# Изученные команды Linux

- pwd - показать текущий каталог
- ls -la - подробный список файлов, включая скрытые
- cd - перейти в каталог
- mkdir -p - создать вложенные каталоги
- touch, cp, mv, rm - создать, копировать, переместить, удалить файл
- cat, less, head, tail - просмотр файлов
- grep, find - поиск строк и файлов
- chmod, chown - права доступа и владелец
- ps, top, kill - работа с процессами
- ip addr, ping, curl, ss - сеть
- Linux: > перезаписывает файл, >> дописывает, | передаёт вывод
